# SWE-GPT-Agentic-Knowledge-Assistant
Developed CodeSage AI, an Agentic RAG-based Software Engineering Knowledge Assistant using LangGraph, LangChain, Qdrant, FastAPI, and Hugging Face models. Implemented Adaptive-RAG routing and Corrective-RAG workflows to retrieve, validate, and generate context-aware answers from technical documentation, improving response relevance and reliability.
